# ⚡ KAIROS - Celestial Mentor AI

A sophisticated AI chatbot with encrypted memory, elegant UI, and integration with Google's Gemini API.

## ✨ Features

### Core Functionality
- **🤖 AI-Powered Conversations**: Integrates with Google Gemini API for intelligent responses
- **🔒 Encrypted Memory**: Conversations stored with Fernet encryption
- **💾 Context-Aware**: Maintains conversation history for coherent dialogue
- **🎨 Beautiful UI**: Celestial-themed interface with smooth animations
- **📱 Responsive Design**: Works seamlessly on desktop and mobile
- **🛡️ Security First**: API keys via environment variables, encrypted storage

### Technical Improvements

**Security Enhancements:**
- API keys stored in `.env` file (not hardcoded)
- Encrypted conversation memory with automatic key generation
- Input validation and sanitization
- Error handling without exposing sensitive information

**Code Quality:**
- Modular class-based architecture
- Comprehensive logging system
- Type hints for better code clarity
- Memory management with size limits
- Proper exception handling throughout

**UI/UX Improvements:**
- Loading indicators during API calls
- Error messages with graceful degradation
- Smooth animations and transitions
- Enter key support for sending messages
- Auto-scroll to latest message
- Disabled button states during processing

## 🚀 Quick Start

### Prerequisites
- Python 3.8 or higher
- Google Gemini API key ([Get one here](https://makersuite.google.com/app/apikey))

### Installation

1. **Clone or download the files:**
```bash
# Create a project directory
mkdir kairos-ai
cd kairos-ai
```

2. **Install dependencies:**
```bash
pip install -r requirements.txt
```

3. **Configure your API key:**
```bash
# Copy the example environment file
cp .env.example .env

# Edit .env and add your Gemini API key
# GEMINI_API_KEY=your_actual_api_key_here
```

4. **Run the application:**
```bash
python main.py
```

5. **Open your browser:**
Navigate to `http://localhost:5000`

## 📋 Configuration

### Environment Variables

Create a `.env` file with the following:

```env
# Required: Your Gemini API Key
GEMINI_API_KEY=your_gemini_api_key_here

# Optional: Custom API endpoint
GEMINI_API_URL=https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent
```

### Memory Settings

Edit these constants in `main.py` if needed:

```python
MAX_MEMORY_SIZE = 100      # Maximum conversation entries to store
CONTEXT_WINDOW = 2000      # Characters of context sent to AI
```

## 🏗️ Architecture

### Project Structure
```
kairos-ai/
├── main.py                 # Main application file
├── requirements.txt        # Python dependencies
├── .env                   # Configuration (create this)
├── .env.example           # Configuration template
├── kairos_memory.json     # Encrypted conversation storage (auto-generated)
├── kairos_key.key         # Encryption key (auto-generated)
└── kairos.log            # Application logs (auto-generated)
```

### Components

**MemoryManager Class:**
- Handles encryption/decryption of conversation data
- Manages conversation history with size limits
- Provides context for AI prompts

**AIHandler Class:**
- Manages communication with Gemini API
- Constructs prompts with system instructions
- Handles API errors gracefully

**Flask Routes:**
- `/` - Main chat interface
- `/kairos` - POST endpoint for chat messages
- `/health` - Health check endpoint

## 🔧 Advanced Usage

### Production Deployment

For production, use a WSGI server like Gunicorn:

```bash
# Install gunicorn (already in requirements.txt)
pip install gunicorn

# Run with gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 main:app
```

### Logging

Logs are written to both console and `kairos.log`:

```python
# Adjust log level in main.py
logging.basicConfig(level=logging.INFO)  # or DEBUG, WARNING, ERROR
```

### Customizing the AI Personality

Edit the `system_prompt` in the `AIHandler.generate_response()` method:

```python
system_prompt = """You are KAIROS, a celestial mentor AI...
[Customize this to change the AI's behavior]
"""
```

## 🛠️ Troubleshooting

### Common Issues

**"API key not configured"**
- Ensure `.env` file exists with valid `GEMINI_API_KEY`
- Check that `python-dotenv` is installed

**"Connection error"**
- Verify internet connection
- Check if API endpoint is correct
- Ensure API key is active and has quota

**Memory not persisting**
- Check file permissions for `kairos_memory.json`
- Verify encryption key file exists

**UI not loading**
- Clear browser cache
- Check browser console for JavaScript errors
- Ensure Flask is running without errors

### Debug Mode

Enable debug mode for development:

```python
# In main.py, change the last line:
app.run(host="0.0.0.0", port=5000, debug=True)
```

## 🔐 Security Considerations

1. **Never commit `.env` file** - Add it to `.gitignore`
2. **Keep encryption key safe** - Backup `kairos_key.key` securely
3. **Use HTTPS in production** - Behind a reverse proxy (nginx/Apache)
4. **Rate limiting** - Consider adding rate limiting for public deployments
5. **Input validation** - Messages are limited to 2000 characters
